# Z-Cipher

Z Cipher (Z–QCT/OMNI Cipher) teaching-simulation protocol repo: chaos mixing, VM-style obfuscation, threshold shadow components, dynamic seeds, multi-replica sharding, bidirectional translation. Specs, principles, prompts, tests included. For cryptography education only; not production-grade encryption, no real personal data.
